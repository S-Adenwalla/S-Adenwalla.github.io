# Sarosh Adenwalla — personal academic website

A responsive, GitHub Pages-ready personal academic website based on the information in the original site.

## Files

- `index.html` — page structure and content
- `main.css` — responsive styling
- `Me.jpeg` — profile image

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `main.css`, and `Me.jpeg` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the main branch and `/ (root)`.
5. Save. GitHub will publish the site.

The site uses Google Fonts for typography; the rest of the page is plain HTML/CSS/JavaScript and needs no build process.
